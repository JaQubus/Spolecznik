# Choice

Radios, checkboxes and the 1–5 rating scale, always in a fieldset with a legend.

Consumer provides: the legend (the question), option labels, optional per-option hint.

- Native inputs, restyled. The whole label row is the hit area, at least `target-min` tall.
- Checked = `ink` fill (not green); unchecked ring = `border-strong` (3:1+).
- Ratings: a `hm-scale` of radios 1–5 with the ends written out. Never stars, never colour alone.
- More than 5 options: a select or a search field.
